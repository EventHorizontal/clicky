# Clicky
Clicky is a terminal-based typing practice app made for fun, practice and because web-based solution add significant delay when typing fast.

# Keymap
- `ESC`: Quit App
- `Alt+C`: Toggle **C**apital Letters (and Refresh the prompt)
- `Alt+E`: Toggle **E**nclosing Characters like `()` (and Refresh the prompt)
- `Alt+S`: Toggle **S**uffix Characters like `.` (and Refresh the prompt)
- `Alt+N`: Toggle **N**umbers (and Refresh the prompt)
- `INS` or `Alt+R`: **R**efresh prompt
